# Phased build prompts

1. **Extractor:** build an open-source, cross-platform git summarizer that outputs only allow-listed counts/date ranges and a signed schema. Add golden repos, tamper tests, and an interactive privacy preview.
2. **Review operations:** add consent records, reviewer authentication, calibrated question banks, double-scoring samples, appeals, and structured audit events.
3. **Credential:** implement expiring/revocable proof links, freshness, evidence limitations, accessible recruiter views, abuse controls, and deletion workflows.
4. **Pilot:** add recruiter comparison, outcome instrumentation, ATS export, billing, support runbooks, and dashboards for completion, reviewer variance, repeat requests, and adverse impact. Do not add generative scoring.
